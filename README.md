# first-pr-practice

This is a a small demo repository created to practice submitting a pull request with Claude Code.

## Purpose

Learn the full workflow: branch, commit, push, and open a PR on GitHub.

## Guide de communication — Ville de Redon

Le dossier [`guide/`](guide/) contient la version interactive du guide de communication
visuelle de la Ville de Redon : un mini site à ouvrir dans le navigateur, et une version
en un seul fichier à diffuser. Voir [`guide/README.md`](guide/README.md).
